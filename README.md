# MBTI로 살아가는 세상

## 프로젝트 소개
이 프로젝트는 다양한 재미있는 MBTI 테스트를 통해 개인의 성격 유형을 알아보고, 친구들과 공유하며, 주변 사람들의 MBTI 유형을 확인할 수 있는 플랫폼입니다.

## 주요 기능
- **MBTI 테스트**: 다양하고 재미있는 MBTI 테스트를 통해 자신의 성격 유형을 알아볼 수 있습니다.
- **결과 공유**: 테스트 결과를 링크와 이미지로 생성해 소셜 미디어 또는 친구들과 쉽게 공유할 수 있는 기능을 제공합니다.
- **커뮤니티 소통**: 자신의 MBTI 유형을 기반으로 캐릭터와 미니홈피를 생성해, 주변 친구들과 소통할 수 있는 기능을 제공합니다.  
- **유형 통계**: 주변 친구들의 MBTI 유형을 확인하고, 어떤 유형이 많은지 통계적으로 분석할 수 있는 기능을 포함합니다.

## 사용 방법
1. **원하는 MBTI 테스트 선택** : 원하는 테스트를 선택합니다.
2. **회원 / 비회원 선택** : 카카오 로그인을 통해 회원 정보를 가져오거나 (간편 회원가입) 비회원으로 테스트를 진행 합니다. 
   * ※ 단, 비회원은 테스트 결과를 기록할 수 없습니다.
3. **MBTI 테스트 진행**: 선택한 테스트를 진행합니다.
4. **결과 확인**: 테스트가 완료되면 자신의 MBTI 유형과 설명을 확인할 수 있습니다.
   - ※ 로그인한 회원은 자동으로 결과가 기록됩니다. (My page 에서 확인 가능)
5. **결과 공유**: 결과 페이지에서 소셜 미디어로 공유하거나 친구에게 직접 전송할 수 있습니다.
   - ※ Url 공유 또는 이미지로 저장
6. **커뮤니티 참여**: 자신의 MBTI 유형에 맞는 커뮤니티에 참여하여 다른 사람들과 의견을 나눌 수 있습니다.
